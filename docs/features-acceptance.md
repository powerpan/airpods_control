## 準備

1. 用普通、不敏感的文本窗口作為被遮擋內容。先在內置顯示器確認解除按鈕可點擊，避免首次測試就依賴尚未驗證的外屏或全屏行為。
2. 佩戴待測 AirPods，確認連接到這台 Mac；在菜單欄打開 **運動數據調試**，選擇 **AirPods** 並開始採集。不要使用“模擬數據”完成硬件驗收。
3. 允許系統運動權限，確認實時計數增加、頻率出現。分別檢查單屏、多屏及不同兼容硬件場景，公開記錄只保留行為和結論。
4. 以自然舒適姿態正視屏幕。不需要強行達到某個角度；如不舒服，調小設置或跳過測試。

## Privacy Shield

| 步驟 | 操作 | 應看到的結果 |
| --- | --- | --- |
| 手動覆蓋 | 選擇“立即遮擋所有屏幕” | 每個已連接顯示器實際模糊底下窗口，能看出背景色彩變化而不是固定色板；小字應難以辨認，每屏都有解除按鈕。額外檢查大字號和高對比內容，系統材質不保證所有內容都不可讀 |
| 手動解除 | 分別點擊解除按鈕、再試 Esc | 覆蓋層移除，應用和鍵盤操作恢復；Esc 需覆蓋窗口收到鍵盤事件 |
| 手動保持 | 手動進入後轉頭、回正 | 不自動揭開；手動遮擋保持到明確解除 |
| 準備自動檢測 | 開啓自動隱私保護，選擇“校準屏幕中立方向”，正視並保持 | 狀態進入“正在留意頭部朝向”；未校準時不能直接觸發自動判斷 |
| 短暫越界 | 緩慢轉頭剛超過閾值後，在觸發延遲內回正 | 不應因一次短暫越界遮擋 |
| 穩定離開 | 向左、向右分別超過閾值並保持 | 默認 35°、0.6 秒後遮擋；實際出現還包含傳感器、顯示刷新及窗口調度延遲 |
| 遲滯 | 遮擋後保持在觸發與恢復閾值之間 | 不應頻繁開關；尚未回到恢復範圍時繼續遮擋 |
| 自動恢復 | 緩慢回到中立並保持 | 默認偏差在 20°以內、穩定 0.5 秒後恢復 |
| 手動解除後的離開姿態 | 自動遮擋時按 Esc，但頭仍偏向一側 | 不應立即重新遮擋；先回中立並穩定後才重新就緒 |
| 改參數 | 調整角度/延遲，再次校準和測試 | UI 數值與實際設置一致；恢復範圍始終小於觸發閾值 |
| 關閉自動檢測 | 遮擋中關閉自動檢測 | 已有遮擋保持，需手動解除；關閉自動檢測本身不揭開內容 |

用舒適的轉頭範圍測試即可；如果默認 35°不合適，可先把觸發角降到 20°並相應調整恢復範圍。這裡檢驗的是閾值行為，不是測量人體活動能力。

## 離座偵測

先在 **功能設置 → 隱私保護** 開啓 **持續行走後保持遮擋**，確認活動服務狀態。坐在書桌前、面向屏幕主動校準，等候重新就緒後才開始測試。活動 API 需要 macOS 15 或更新版本；Pro 2、Pro 3 都應分別確認運行時可用性，不把某一型號的姿態採集成功當作活動識別成功。

下表是人工驗收步驟，硬件項目均仍待測。低置信度、矛盾標籤和遲到事件無法可靠靠人體重現，應使用 Mock Activity Source 驗證，再與真實回調觀察分開記錄。

| 情境 | 操作 | 應看到的結果 |
| --- | --- | --- |
| 普通轉頭 | 保持坐姿，向一側轉頭達到原有閾值，再回正 | 沿用原有遮擋與自動恢復；不能僅因轉頭變成離座保持 |
| 從在位到行走 | 完成書桌校準，等離座偵測冷卻結束後起身，安全地持續走動 | 官方可靠步行證據被接收並持續約 2.5 秒後，進入離座保持；總延遲包含分類與回調延遲，並受重新就緒冷卻影響，不能用 2.5 秒作硬件延遲承諾 |
| 臨時遮擋升級 | 先轉頭觸發遮擋，再起身走動 | 文案變為離座保持；既有覆蓋窗口不閃爍、不重新出現動畫 |
| 離座後靜止 | 離座保持成立後，在別處停止行走並靜止 | 遮擋持續，不把 stationary 當成返回書桌 |
| 離座後回正 | 保持離座狀態，讓頭部朝向先前校準的屏幕方向 | 遮擋持續，不因 yaw 回到中立而解除 |
| 手動解除與重新就緒 | 返回書桌，分別試覆蓋按鈕、菜單解除、Esc、⇧⌘P；每次先建立新的離座保持 | 原有事件範圍內可解除，等待穩定姿態重新校準及冷卻後恢復正常監測，不立即反覆遮擋；沒有數據時明確提示手動校準 |
| 證據不足 | 坐姿下短暫點頭、低頭與轉頭；用 Mock 送低置信度、混合標籤、過舊及重置前的事件 | 不能觸發離座保持。真實動作仍可能被官方分類器誤判，觀察與 Mock 規則結果分開記錄 |
| 中斷與基準變更 | 已離座保持後，分別斷開耳機、停止姿態採集、休眠／喚醒、重新佩戴；用 Mock 改變參考標識 | 已有遮擋持續；重新校準或恢復連接不能自行解除。未成立的行走候選不能跨中斷累積 |
| 頸部活動與開關 | 進入頸部活動並完成轉頭／側傾；另在離座保持中關閉自動隱私或離座開關 | 活動期間不建立離座判定；關閉開關不解除已有保持遮擋。結束活動後回書桌重新校準 |
| 活動服務不可用 | 在不支持的系統／耳機或權限被拒時查看狀態；也以 Mock 模擬不可用 | 清楚顯示原因，普通轉頭遮擋與手動遮擋仍可使用；不能顯示已識別離座 |

另檢查尚未校準時長時間靜止，不會自動建立書桌基準；已離座後長時間靜止，也不會重設基準。手動解除後若姿態不穩定，應保持等待狀態並允許用現有入口重新校準，不要求新的解鎖動作。

採用的活動來源、證據處理與誤判邊界見 [離座偵測與保持遮擋](departure-detection.md)。本功能不證明人在某個空間位置，未站起行走、短距離挪動及官方分類器未給出可靠事件時可能漏報。

## 數據中斷時的保持行為

下面每種情況應單獨測試並記錄，不把一次成功當作全部情況通過。

1. 自動進入遮擋後，將耳機放回充電盒，或在系統藍牙界面斷開耳機。
2. 檢查覆蓋層仍在，提示數據不可用/需手動解除。等一段時間再觀察，不應超時後自動揭開。
3. 重新連接並佩戴，確認即使數據恢復，舊遮擋仍需明確手動解除。
4. 使用覆蓋按鈕解除；回到工作姿態重新校準，再檢查自動觸發。
5. 對“從調試窗口停止採集”和“系統睡眠後喚醒”重複檢查。停止採集不等於解除遮擋；睡眠期間系統鎖屏行為不由本應用控制。
6. 若只是短暫樣本間斷，之前累積的觸發/恢復保持時間也應清零，而不是跨間斷繼續計算。

## 已就緒時的資料中斷遮擋

確認 **功能設置 → 隱私保護 → 已就緒時遺失耳機資料即遮擋** 為開啓（預設）。每項先校準並等菜單欄顯示帶勾盾牌（已就緒），在未遮擋狀態下開始。

1. 將耳機放回充電盒：應立即遮擋，提示資料中斷並需手動解除；重新佩戴、資料恢復後遮擋仍保持。
2. 在系統藍牙界面斷開耳機，或帶著耳機走出藍牙範圍：同樣遮擋並保持到手動解除。
3. 系統進入睡眠再喚醒：喚醒後遮擋仍在，需手動解除。
4. 從調試窗口 **停止採集**：不應遮擋；菜單欄改為帶感嘆號盾牌（未就緒），約 5 秒後出現未就緒通知。
5. 進入頸部活動後取下耳機：不應遮擋；結束活動後也不應因參考清除而遮擋。
6. 關閉此設定後重複第 1 步：不遮擋，只停止偵測並顯示等待校準；約 5 秒後出現未就緒通知。
7. 退出應用：不應出現遮擋或通知。

## 未就緒通知

1. 首次就緒時系統應詢問通知權限；拒絕後應用其他行為不變。
2. 剛啓動且尚未校準時不應通知。
3. 已就緒後調整設置滑桿或重新校準，若 5 秒內回到已就緒，不應通知。
4. 連續兩次在 5 分鐘內失去就緒狀態，只應出現一則通知。
5. 應用窗口在前台時通知也應以橫幅顯示。

任何測試中，如鍵盤焦點被其他系統界面拿走，優先點擊覆蓋層上的 **解除遮擋**。退出或系統強制退出本應用會銷毀覆蓋窗口，也會暴露原窗口；這不是帶認證的鎖屏機制。

## Neck Exercise

1. 確認未遮擋，然後選擇 **開始頸部活動**。如果正在遮擋，先明確解除，不能通過打開活動窗口隱式揭開內容。
2. 面向屏幕、自然坐好，點擊 **校準並開始**。模型面向你，做鏡像動作：模型向它的右側轉，你向左轉。先小幅核對實際幅度的方向；若識別相反，結束活動，在設置裡反轉對應軸後重新開始。
3. 按左轉、右轉、左側傾、右側傾、輕微低頭的流程，緩慢達到或超過設定幅度。保持條應開始累積，連續滿足時長後進入返回階段；回中立保持後才增加完成數。
4. 低於閾值靜止等待、向相反方向轉動或只移動非目標軸：動作不應僅因為時間經過而完成。中途落回閾值以下後，保持計時應重新開始。
5. 在舒適範圍內稍微超過閾值，無需停在一個精確角度，其他軸輕微活動也不阻止達幅計時。模型動畫停在示範姿態等待你，不應單憑動畫結束增加完成數。
6. 在目標階段和返回階段分別暫停：保持計時應清除，暫停期間不增加完成數；繼續後需要有效姿態完成當前階段。
7. 使用 **跳過**：跳過數量增加，完成數量不增加。全部跳過時，結果頁不應暗示五個動作都已完成。
8. 活動中斷開耳機：姿態判斷暫停、目標不再自動完成；恢復後按提示重新校準。不要把凍結畫面誤認為新的傳感器數據。
9. 分別測試 **結束活動** 和關閉活動窗口。菜單欄仍駐留；退出活動後需回到工作方向重新校準自動隱私檢測。

默認幅度為轉頭 20°、側傾 12°、低頭 10°。允許調小、跳過或隨時結束；出現疼痛、眩暈或不適時停止。活動結果不用於醫療判斷。

## 兩功能協調

- 保持自動隱私檢測開啓，再進入活動。活動中的左右轉頭不得觸發自動遮擋，原自動開關應保持開啓狀態，而非被永久關閉。
- 活動中手動遮擋：覆蓋層出現，活動暫停。解除後不能把遮擋期間的姿態計作完成動作。
- 完成或提前結束活動：恢復原自動設置，但要求重新校準工作中立位置；不能沿用活動過程中偏轉的姿態作為工作方向。
- 同時打開調試窗口，選擇 **暫停顯示**：只凍結調試顯示，功能規則仍基於採集流運行；選擇 **停止傳感器採集**：兩個功能都應識別為數據不可用。

分別在 Pro 2 與 Pro 3 上做動作測試；以下窗口場景主要取決於 Mac 系統與顯示配置，可共用場景記錄。

| 旋轉 / 分辨率縮放 | 覆蓋範圍與按鈕位置更新 | 待測 |

窗口層級及 Spaces 標誌只是公開 AppKit 的呈現請求。更高層窗口、安全提示或系統管理界面可能在覆蓋層之上；錄屏/遠程控制也不能保證一定包含此覆蓋層。技術依據和完整邊界見 [privacy-window-limitations.md](privacy-window-limitations.md)。

## 記錄方式

公開記錄只包含測試步驟、觀察結果、異常和尚未完成的檢查，不附參與者、賬號、設備歸屬、精確環境組合、絕對路徑或地理與時間信息。沒有執行的項寫“未測”，不要寫“通過”。真實採集頻率、動作延遲和漂移需要各自測量，自動化樣本測試不提供這些指標。
